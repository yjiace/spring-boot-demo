## 1. Spring Boot 基础

### 1.1 什么是 Spring Boot？
Spring Boot 是一个基于 Spring 框架的快速开发脚手架，它简化了 Spring 应用的创建、配置和部署过程。

### 1.2 引入依赖
```xml
<parent>
    <groupId>org.springframework.boot</groupId>
    <artifactId>spring-boot-starter-parent</artifactId>
    <version>3.5.7</version>
</parent>

<dependency>
    <groupId>org.springframework.boot</groupId>
    <artifactId>spring-boot-starter-web</artifactId>
</dependency>
```

### 1.3 启动类配置
```java
@SpringBootApplication
public class SpringBootDemoApplication {
    public static void main(String[] args) {
        SpringApplication.run(SpringBootDemoApplication.class, args);
    }
}
```

**核心注解说明：**
| 注解 | 作用 |
|------|------|
| `@SpringBootApplication` | 组合注解，包含 `@Configuration`、`@EnableAutoConfiguration`、`@ComponentScan` |
| `@Configuration` | 标识配置类，替代 XML 配置 |
| `@EnableAutoConfiguration` | 开启自动配置 |
| `@ComponentScan` | 扫描组件，默认扫描启动类所在包及子包 |

## 2. JPA 审计功能

### 2.1 什么是 JPA 审计？
JPA 审计（Auditing）是 Spring Data JPA 提供的功能，可以自动记录实体的创建人、创建时间、修改人、修改时间。

### 2.2 使用步骤

**步骤1：引入 JPA 依赖**
```xml
<dependency>
    <groupId>org.springframework.boot</groupId>
    <artifactId>spring-boot-starter-data-jpa</artifactId>
</dependency>
```

**步骤2：开启审计功能**

在启动类中添加注解 `@EnableJpaAuditing`：
```java
@EnableJpaAuditing
@SpringBootApplication
public class SpringBootDemoApplication {
    // ...
}
```

**步骤3：实现 AuditorAware 接口**

用于获取当前操作用户的信息：
```java
@Configuration
class SpringSecurityAuditorAware implements AuditorAware<String> {

    @Override
    public Optional<String> getCurrentAuditor() {
        // 返回当前登录用户ID
        return Optional.of(UserUtil.getCurrentAuditor());
    }
}
```

**步骤4：在实体类中添加审计监听器**

```java
@MappedSuperclass
@EntityListeners({AuditingEntityListener.class})
public class BaseEntity<T> {
    // 审计字段...
}
```

**步骤5：添加审计字段注解**

```java
@CreatedBy
@Column(updatable = false)
private T createdBy;

@CreatedDate
@JsonFormat(pattern = "yyyy-MM-dd HH:mm:ss", timezone = "GMT+08:00")
@Column(updatable = false)
private LocalDateTime createdTime;

@LastModifiedBy
private T updatedBy;

@LastModifiedDate
@JsonFormat(pattern = "yyyy-MM-dd HH:mm:ss", timezone = "GMT+08:00")
private LocalDateTime updatedTime;
```

### 2.3 审计注解详解

| 注解 | 作用 | 生效时机 |
|------|------|----------|
| `@CreatedBy` | 记录创建人 | 实体**首次保存**时自动填充 |
| `@CreatedDate` | 记录创建时间 | 实体**首次保存**时自动填充 |
| `@LastModifiedBy` | 记录最后修改人 | 实体**每次保存**时自动更新 |
| `@LastModifiedDate` | 记录最后修改时间 | 实体**每次保存**时自动更新 |
| `@EntityListeners` | 指定实体监听器 | 监听实体生命周期事件 |

> **注意**：`@Column(updatable = false)` 确保创建信息不会被后续更新操作覆盖。

## 3. JPA 关联关系与软删除

### 3.1 多对多关联 @ManyToMany

用于建立两个实体之间的多对多关系，如用户和角色：

```java
@ManyToMany(cascade = CascadeType.REFRESH, fetch = FetchType.LAZY)
@JoinTable(
    name = "t_user_role",                              // 中间表名
    joinColumns = {@JoinColumn(name = "user_id")},     // 当前实体外键
    inverseJoinColumns = {@JoinColumn(name = "role_id")} // 关联实体外键
)
private List<Role> roles = new ArrayList<>();
```

**参数说明：**
| 参数 | 说明 |
|------|------|
| `cascade` | 级联操作类型：`REFRESH`（刷新）、`PERSIST`（新增）、`MERGE`（更新）、`REMOVE`（删除） |
| `fetch` | 加载策略：`LAZY`（延迟加载）、`EAGER`（立即加载） |

### 3.2 软删除 @SQLRestriction

软删除是指不物理删除数据，而是通过标志字段标记为已删除：

```java
@Entity
@SQLRestriction(" deleted = 'N' ")  // 查询时自动过滤已删除数据
public class User extends BaseEntity<String> {
    
    @JsonIgnore
    private String deleted = "N";  // Y：已删除，N：未删除
}
```

> **注意**：`@SQLRestriction` 是 Hibernate 6.3+ 的新注解，替代了已废弃的 `@Where`。

## 4. Spring Security 安全框架

### 4.1 什么是 Spring Security？
Spring Security 是一个强大的认证和授权框架，提供了全面的安全解决方案。

### 4.2 引入依赖
```xml
<dependency>
    <groupId>org.springframework.boot</groupId>
    <artifactId>spring-boot-starter-security</artifactId>
</dependency>
```

### 4.3 安全配置类

```java
@Configuration
@EnableWebSecurity
public class SecurityConfig {

    @Bean
    public SecurityFilterChain filterChain(HttpSecurity http) throws Exception {
        return http
            .cors(Customizer.withDefaults())              // 开启跨域支持
            .authorizeHttpRequests(authorize ->           // 请求授权配置
                authorize
                    .requestMatchers(HttpMethod.OPTIONS, "/**").permitAll()
                    .anyRequest().permitAll())            // 允许所有请求
            .csrf(AbstractHttpConfigurer::disable)        // 禁用 CSRF
            .httpBasic(Customizer.withDefaults())         // HTTP Basic 认证
            .headers(headers ->                           // 安全头配置
                headers.frameOptions(HeadersConfigurer.FrameOptionsConfig::sameOrigin))
            .build();
    }

    /**
     * 密码加密器
     */
    @Bean
    public BCryptPasswordEncoder bCryptPasswordEncoder() {
        return new BCryptPasswordEncoder();
    }
}
```

### 4.4 核心注解说明

| 注解 | 作用 |
|------|------|
| `@EnableWebSecurity` | 启用 Web 安全配置 |
| `@Configuration` | 标识为配置类 |

### 4.5 BCrypt 密码加密

BCrypt 是一种安全的密码哈希算法，特点：
- 自动加盐，防止彩虹表攻击
- 可配置计算复杂度
- 同一密码每次加密结果不同

```java
// 加密密码
String encodedPassword = bCryptPasswordEncoder.encode("plainPassword");

// 验证密码
boolean matches = bCryptPasswordEncoder.matches("plainPassword", encodedPassword);
```

## 5. JWT 认证机制

### 5.1 什么是 JWT？
JWT（JSON Web Token）是一种开放标准（RFC 7519），用于在各方之间安全地传输信息。

### 5.2 JWT 结构
```
Header.Payload.Signature
```
- **Header**：算法类型和令牌类型
- **Payload**：载荷数据（用户信息、过期时间等）
- **Signature**：签名，用于验证令牌完整性

### 5.3 JWT 配置类

```java
@Data
@Configuration
@ConfigurationProperties("jwt")
public class JwtConfig {

    private Boolean enable = true;          // 是否开启鉴权
    private Boolean sso = false;            // 是否单点登录
    private String tokenHead = "Authorization"; // token请求头名称
    private String redisKey = "login_token_key:"; // Redis键前缀
    private Integer expiration = 120;       // token过期时间（分钟）
    private Integer refreshTime = 60 * 60 * 24 * 30; // 刷新令牌最大时长（秒）
    private String publicKey;               // RSA公钥
    private String privateKey;              // RSA私钥
    private List<String> authUrl;           // 登录即可访问的URL
    private List<String> anonUrl;           // 匿名可访问的URL
}
```

### 5.4 JWT 过滤器核心逻辑

```java
public class JwtTokenFilter extends OncePerRequestFilter {

    @Override
    protected void doFilterInternal(HttpServletRequest request, 
                                    HttpServletResponse response,
                                    FilterChain chain) {
        // 1. 判断是否开启鉴权
        // 2. 获取并解析 Token
        // 3. 验证签名（RSA算法）
        // 4. 检查Token是否过期
        // 5. 与Redis中存储的Token比对（单点登录）
        // 6. 验证用户权限
        // 7. 放行或拒绝请求
    }
}
```

### 5.5 配置属性绑定

`@ConfigurationProperties` 用于将配置文件中的属性绑定到 Java Bean：

```yaml
jwt:
  enable: false
  sso: true
  expiration: 120
  public-key: MIGfMA0GCSqGSIb3DQEBAQUAA4GNAD...
  private-key: MIICdwIBADANBgkqhkiG9w0BAQEFA...
```

### 6.3 自定义 RedisTemplate

```java
@Configuration
public class RedisConfig {

    @Bean
    public RedisTemplate<String, Object> jsonRedisTemplate(
            RedisConnectionFactory connectionFactory) {
        RedisTemplate<String, Object> template = new RedisTemplate<>();
        template.setConnectionFactory(connectionFactory);
        
        // Jackson序列化配置
        ObjectMapper objectMapper = new ObjectMapper();
        objectMapper.configure(DeserializationFeature.FAIL_ON_UNKNOWN_PROPERTIES, false);
        
        // 处理LocalDateTime序列化
        JavaTimeModule javaTimeModule = new JavaTimeModule();
        javaTimeModule.addSerializer(LocalDateTime.class, 
            new LocalDateTimeSerializer(DateTimeFormatter.ofPattern("yyyy-MM-dd HH:mm:ss")));
        objectMapper.registerModule(javaTimeModule);
        
        // 设置序列化器
        Jackson2JsonRedisSerializer<Object> serializer = 
            new Jackson2JsonRedisSerializer<>(objectMapper, Object.class);
        
        template.setKeySerializer(new StringRedisSerializer());
        template.setValueSerializer(serializer);
        template.setHashKeySerializer(new StringRedisSerializer());
        template.setHashValueSerializer(serializer);
        
        return template;
    }
}
```

### 6.4 Redis 操作示例

## 7. JPA Specification 动态查询

### 7.1 什么是 Specification？
Specification 是 Spring Data JPA 提供的动态查询构建方式，可以根据条件灵活组合查询语句。

### 7.2 Repository 继承

```java
@NoRepositoryBean
public interface BaseRepository<T, ID extends Serializable> 
    extends JpaRepository<T, ID>, JpaSpecificationExecutor<T> {
}
```

> `@NoRepositoryBean` 表示这是一个基础接口，Spring 不会为它创建代理实现。

### 7.3 动态条件构建器

```java
public class SimpleSpecificationBuilder<T> {

    private final List<SpecificationOperator> operators;
    private Sort sort;

    /**
     * 构造方法：根据Map参数自动解析查询条件
     * Map键的格式：join_operator_key（用下划线分隔）
     * 例如：AND_EQ_username 表示 AND username = ?
     */
    public SimpleSpecificationBuilder(Map<String, Object> map) {
        operators = new ArrayList<>();
        for (Map.Entry<String, Object> entry : map.entrySet()) {
            String[] keys = entry.getKey().split("_", 3);
            if (keys.length == 3) {
                // keys[0]: join (AND/OR)
                // keys[1]: operator (EQ/LIKE/IN等)
                // keys[2]: key (字段名)
                this.add(keys[2], map.get(entry.getKey()), 
                    SpecificationOperator.stringToOperator(keys[1]), keys[0]);
            }
        }
    }

    public Specification<T> getSpecification() {
        return new SimpleSpecification<>(operators, sort);
    }
}
```

### 7.4 支持的操作符

| 操作符 | 说明 | 示例 |
|--------|------|------|
| `EQ` | 等于 | `AND_EQ_status` |
| `NEQ` | 不等于 | `AND_NEQ_deleted` |
| `LIKE` | 模糊匹配（包含） | `AND_LIKE_username` |
| `LEFTLIKE` | 左模糊（以...结尾） | `AND_LEFTLIKE_name` |
| `RIGHTLIKE` | 右模糊（以...开头） | `AND_RIGHTLIKE_name` |
| `NOTLIKE` | 不包含 | `AND_NOTLIKE_content` |
| `GT` | 大于 | `AND_GT_age` |
| `GE` | 大于等于 | `AND_GE_createTime` |
| `LT` | 小于 | `AND_LT_age` |
| `LE` | 小于等于 | `AND_LE_updateTime` |
| `IN` | 包含多个值 | `AND_IN_status` |
| `NOTIN` | 不包含多个值 | `AND_NOTIN_type` |
| `BETWEEN` | 区间查询 | `AND_BETWEEN_price` |
| `NULL` | 为空 | `AND_NULL_deletedAt` |
| `NOTNULL` | 不为空 | `AND_NOTNULL_email` |
| `JSONCONTAIN` | JSON数组包含 | `AND_JSONCONTAIN_tags` |

### 7.5 使用示例

```java
// 构建查询条件
Map<String, Object> params = new HashMap<>();
params.put("AND_LIKE_username", "admin");
params.put("AND_EQ_status", "Y");

// 执行查询
Page<User> users = userRepository.findAll(
    new SimpleSpecificationBuilder<User>(params).getSpecification(),
    PageRequest.of(0, 10)
);
```

## 8. MapStruct 对象映射

### 8.1 什么是 MapStruct？
MapStruct 是一个用于 Java Bean 之间映射的代码生成器，在编译时生成映射代码，性能优于运行时反射。

### 8.2 引入依赖
```xml
<dependency>
    <groupId>org.mapstruct</groupId>
    <artifactId>mapstruct</artifactId>
    <version>1.6.2</version>
</dependency>
<dependency>
    <groupId>org.mapstruct</groupId>
    <artifactId>mapstruct-processor</artifactId>
    <version>1.6.2</version>
</dependency>
```

### 8.3 配置编译器插件

```xml
<plugin>
    <groupId>org.apache.maven.plugins</groupId>
    <artifactId>maven-compiler-plugin</artifactId>
    <configuration>
        <annotationProcessorPaths>
            <path>
                <groupId>org.mapstruct</groupId>
                <artifactId>mapstruct-processor</artifactId>
                <version>${mapstruct.version}</version>
            </path>
            <path>
                <groupId>org.projectlombok</groupId>
                <artifactId>lombok</artifactId>
            </path>
            <!-- Lombok与MapStruct兼容绑定 -->
            <path>
                <groupId>org.projectlombok</groupId>
                <artifactId>lombok-mapstruct-binding</artifactId>
                <version>0.2.0</version>
            </path>
        </annotationProcessorPaths>
    </configuration>
</plugin>
```

### 8.4 定义 Mapper 接口

```java
@Mapper(nullValuePropertyMappingStrategy = NullValuePropertyMappingStrategy.IGNORE)
public interface UserMapper {

    UserMapper INSTANCE = Mappers.getMapper(UserMapper.class);

    // Entity -> Response
    UserResponse toResponse(User user);

    // Request -> Entity (更新已有对象)
    void init(@MappingTarget User entity, UserRequest request);
}
```

**核心注解：**
| 注解 | 作用 |
|------|------|
| `@Mapper` | 标识映射器接口 |
| `@MappingTarget` | 表示目标对象已存在，进行属性更新 |
| `nullValuePropertyMappingStrategy` | 空值处理策略：`IGNORE` 忽略空值 |

### 8.5 使用示例

```java
// Entity 转 Response
UserResponse response = UserMapper.INSTANCE.toResponse(user);

// Request 更新 Entity
UserMapper.INSTANCE.init(user, userRequest);
```

## 9. 全局响应封装与统一异常处理

### 9.1 统一响应结果类

```java
@Getter
@JsonInclude(JsonInclude.Include.NON_NULL)  // null值不序列化
public class SysResult<T> implements Serializable {

    private Integer code;
    private String message;
    private T data;

    public static <T> SysResult<T> success(T data) {
        return result(HttpStatus.OK, data);
    }

    public static <T> SysResult<T> failure(String msg) {
        return new SysResult<>(HttpStatus.INTERNAL_SERVER_ERROR.value(), msg, null);
    }
}
```

### 9.2 全局响应封装

使用 `@RestControllerAdvice` + `ResponseBodyAdvice` 自动封装响应：

```java
@RestControllerAdvice
public class ResponseSysResultAdvice implements ResponseBodyAdvice<Object> {

    @Override
    public boolean supports(MethodParameter returnType, Class<?> converterType) {
        // 检查类或方法是否有 @ResponseSysResult 注解
        return AnnotatedElementUtils.hasAnnotation(
            returnType.getContainingClass(), ResponseSysResult.class);
    }

    @Override
    public Object beforeBodyWrite(Object body, MethodParameter returnType, ...) {
        if (body instanceof SysResult) {
            return body;  // 已经是 SysResult 直接返回
        }
        return SysResult.success(body);  // 自动封装
    }
}
```

### 9.3 统一异常处理

```java
@RestControllerAdvice
public class ResponseSysResultAdvice {

    @ExceptionHandler(value = Exception.class)
    public Map<String, Object> handler(HttpServletRequest request, Exception e) {
        int code = HttpStatus.INTERNAL_SERVER_ERROR.value();
        if (e instanceof BizException bizException) {
            code = bizException.getCode();
        }
        return Dict.create()
            .set("code", code)
            .set("message", e.getMessage())
            .set("path", request.getRequestURI())
            .set("timestamp", LocalDateTime.now());
    }
}
```

### 9.4 自定义业务异常

```java
public class BizException extends RuntimeException {

    private String msg;
    private Integer code;

    public BizException(String msg) {
        super(msg);
        this.msg = msg;
    }

    public BizException(String msg, Integer code) {
        super(msg);
        this.msg = msg;
        this.code = code;
    }
}
```

## 12. HikariCP 连接池

### 12.1 什么是 HikariCP？
HikariCP 是一个高性能的 JDBC 连接池，Spring Boot 2.x 默认使用。

### 12.2 配置参数
```yaml
spring:
  datasource:
    type: com.zaxxer.hikari.HikariDataSource
    hikari:
      minimum-idle: 2           # 最小空闲连接数
      maximum-pool-size: 10     # 最大连接数
      connection-test-query: SELECT 1  # 连接测试SQL
      max-lifetime: 18000       # 连接最大生命周期(毫秒)
      connection-timeout: 30000 # 连接超时时间(毫秒)
```

### 12.3 关键参数说明

| 参数 | 说明 | 建议值 |
|------|------|--------|
| `minimum-idle` | 空闲连接最小数量 | CPU核心数 |
| `maximum-pool-size` | 连接池最大连接数 | CPU核心数 * 2 + 1 |
| `connection-timeout` | 获取连接超时时间 | 30000ms |
| `max-lifetime` | 连接最大存活时间 | 小于数据库超时时间 |

## 13. Spring Profiles 多环境配置

### 13.1 基本概念
Spring Profiles 允许针对不同环境（开发、测试、生产）使用不同的配置。

### 13.2 配置文件命名规则
```
application.yaml          # 公共配置
application-dev.yaml      # 开发环境
application-test.yaml     # 测试环境
application-prod.yaml     # 生产环境
```

### 13.3 激活指定环境

**方式1：配置文件中指定**
```yaml
spring:
  profiles:
    active: dev
```

**方式2：命令行参数**
```bash
java -jar app.jar --spring.profiles.active=prod
```

**方式3：环境变量**
```bash
export SPRING_PROFILES_ACTIVE=prod
```
